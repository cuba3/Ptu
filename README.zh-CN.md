# Ptu

**Ptu** 是一款基于 Swift、SwiftUI 与 Metal 从零打造的现代原生 macOS 图像编辑器。它提供分层、非破坏性的专业级栅格图像编辑工作流，并针对 Apple Silicon 与 macOS Sequoia 全面优化。

- **平台：** macOS 15.0+（Sequoia）
- **开发语言：** Swift 5
- **渲染：** Metal（基于 GPU 的画布与分块合成）
- **许可证：** Apache License 2.0

---

## 功能清单

### 画布与视图
- 基于 Metal 加速、分块渲染的画布，处理超大图像依然流畅。
- 文档最大支持 **16,000 × 16,000 像素**，分辨率范围 **1 至 2400 PPI**。
- 缩放（放大 / 缩小 / 实际大小 / 适应屏幕）与抓手工具平移。
- 标尺、参考线（可添加水平 / 垂直参考线、清除参考线）、网格叠加与吸附。
- 透明或纯白画布背景。

### 图层
- 像素图层、**调整图层** 与 **可嵌套的组图层**。
- 完整的图层操作：新建、删除、复制、调整顺序（上移 / 下移）、重命名、显示 / 隐藏。
- 图层级 **不透明度** 与 **12 种混合模式**：正常、正片叠底、滤色、叠加、变暗、变亮、颜色减淡、颜色加深、柔光、强光、差值、排除。
- **图层蒙版** —— 显示 / 隐藏、反相、启用 / 停用、绘制与编辑蒙版。
- **剪贴蒙版**，将一个图层裁剪到另一个图层。
- **图层样式（效果）**：描边、投影、颜色叠加、内阴影、外发光、内发光。

### 调整（非破坏性）
- 色阶、曲线、色相 / 饱和度、曝光度、黑白、色彩平衡、渐变映射、颗粒、反相。
- 每项均可作为实时 **调整图层** 添加；多数还提供“烘焙”操作，可直接写入像素。
- **Camera Raw** 调整，用于 RAW 照片调色。

### 滤镜
- 高斯模糊、动感模糊、添加杂色、暗角（Vignette）、泛光 / 发光（Bloom）、色调对比度、抖动（Dither）、镜头校正。

### 选区与蒙版
- 工具：矩形选框、套索（自由绘制）、魔棒、对象选择、色彩范围。
- 智能操作：**选择主体**、**移除背景**、**内容识别填充**、引导式抠像、主体移除。
- 选区编辑：全选、取消选择、反选、羽化、复制 / 剪切 / 粘贴、浮动选区、选区剪贴板。

### 修饰与绘画
- 画笔、仿制图章、修复 / 污点修复、模糊、涂抹。
- 吸管取色与内置颜色拾取器。

### 几何与变换
- 裁剪、自由变换、扭曲、水平 / 垂直翻转、画布翻转、顺时针 / 逆时针旋转 90°、旋转 180°、图像大小、画布大小、修剪。

### 矢量、文字与填充
- 文字工具、形状工具、渐变工具，以及调色板。

### 导入与导出
- **导入 Adobe Photoshop** `.psd` 与大型文档 `.psb`（8 位 RGB）。对于不支持的特性（文字、矢量、图层蒙版、实时调整），会识别并给出转换报告，而非静默丢弃。
- **RAW 显影**（Camera Raw），将 RAW 照片导入编辑器。
- **导出 PNG** 与 **导出 JPEG**。
- 原生 **`.ptu`** 文档格式，用于保存与重新打开工程；支持最近文件列表与重新加载。

### 效率工具
- **命令面板** —— 通过名称搜索并运行任意命令。
- **完全可自定义的快捷键**，带冲突 / 合法性校验，并可跨启动持久化保存。
- **多文档标签页**，可同时处理多个文件。
- 完整的 **撤销 / 重做** 历史记录。
- **设置** 中可切换界面语言。
- **多语言界面**：英语、简体中文、繁體中文、日本語，以及跟随系统。

## 快速开始

### 环境要求
- macOS 15.0 或更高版本
- Xcode 16（或兼容的工具链）
- 已安装 [XcodeGen](https://github.com/yonaskolb/XcodeGen)（`brew install xcodegen`），用于重新生成 Xcode 工程

### 构建与运行
```bash
# 根据 project.yml 重新生成 Xcode 工程
xcodegen generate

# 打开并运行
open Ptu.xcodeproj
# 或在命令行中构建
xcodebuild -scheme Ptu -configuration Debug build
```

应用会注册为原生 `.ptu` 文档的编辑器，并作为 PNG 与 JPEG 文件的查看器。

## 已知限制
- PSD / PSB 导入仅支持 **8 位 RGB**；文字、矢量形状、图层蒙版与实时调整图层会被识别并报告，但不会被重建为可编辑对象。
- RAW 显影依赖内置的 Camera Raw 处理管线。
- 画布单边最大尺寸为 16,000 像素。
